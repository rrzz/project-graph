# Deepen a Project Graph with frontier workers

Use the `frontier-project-graph` skill for a high-judgment architectural survey.
Read its `SKILL.md`, `references/workflow.md`, and `references/worker-contract.md`
before acting.

Frame a small set of distinct high-risk questions. Use frontier-model workers as
read-only candidate producers, then act as the sole orchestrator for identity
resolution, evidence review, assertion writes, and acceptance. Do not substitute
model confidence for repository evidence. Never use line-number anchors, inspect
blocked paths, or lock evidence without explicit review. Use FTS-backed `query`
to seed an investigation; reviewed unlocked graph data remains usable and a
`"reused": true` build is success.
